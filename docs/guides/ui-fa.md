# راهنمای رابط کاربری وب marfin-llm

همهٔ قابلیت‌های برنامه در یک صفحهٔ مرورگر، به فارسی و راست‌به‌چپ. چیز تازه‌ای لازم نیست نصب شود:
فقط پایتون.

## اجرا

```powershell
cd C:\marfin-llm
git pull
# با مدل (همهٔ صفحه‌ها، از جمله «پرسش»):
python scripts\ui.py --model C:\models\Qwen3.5-4B-Q4_K_M.gguf
# یا با LM Studio:
python scripts\ui.py --server lmstudio --model-id qwen3.5-4b
# بدون مدل (همه چیز به جز «پرسش» کار می‌کند):
python scripts\ui.py
```

مرورگر خودش باز می‌شود: http://127.0.0.1:8765. برای بستن، در پنجرهٔ PowerShell کلید `Ctrl+C` را بزنید.
برای داده‌های FRED، پیش از اجرا بنویسید: `$env:FRED_API_KEY="..."` (کلید در هیچ فایلی ذخیره نمی‌شود).
برای زبانه‌های «فارکس» و «سهام آمریکا» (اختیاری): `$env:ALPHAVANTAGE_API_KEY="..."` (نسخهٔ رایگان: فقط دادهٔ روزانه، ۲۵ درخواست در روز برای همهٔ زبانه‌ها روی هم).
برای صورت‌های مالی شرکت‌های آمریکایی (اختیاری): `$env:SEC_CONTACT_EMAIL="you@example.com"`. کمیسیون بورس آمریکا (SEC) درخواست بدون ایمیل تماس را رد می‌کند.
برای زبانهٔ «رمزارزها» کلیدی لازم نیست (حدود ۵ درخواست در دقیقه). با کلید رایگان Demo سقف بالاتر می‌رود: `$env:COINGECKO_DEMO_API_KEY="..."`.

## صفحه‌ها

| صفحه | چه می‌کند |
|---|---|
| داشبورد | خلاصهٔ وضعیت و میان‌بر به همهٔ بخش‌ها |
| بازارها | نُه زبانه: نمای کلی، رمزارزها (قیمت، ارزش بازار، حجم، تغییرات و نمودار ۳۶۵ روزه)، فارکس (۹ جفت‌ارز اصلی، روزانه)، سهام آمریکا (جست‌وجوی نماد، قیمت پایانی روز و صورت‌های مالی سالانه از 10-K)، نرخ مرجع ارزها (۲۹ ارز با مبدل و نمودار ۹۰ روزه)، نرخ بهرهٔ بانک‌های مرکزی (۴۹ منطقه)، اوراق و کالا (بازده اوراق، نفت، گاز، شاخص دلار)، اقتصاد کشورها (۱۰ شاخص بانک جهانی با نمودار مقایسه‌ای) و منابع |
| پرسش | سؤال به فارسی یا انگلیسی. موتور را برای هر سؤال انتخاب می‌کنید: **آفلاین** (مدل محلی) یا **آنلاین** (ارائه‌دهندهٔ انتخابی). مسیر را برنامه انتخاب می‌کند: محاسبه، داده‌های کلان، اسناد یا پاسخ ساده. اعداد با شواهد کنترل می‌شوند و هشدارها بالای پاسخ می‌آیند |
| فرمول‌ها | ۸۵ محاسبهٔ قطعی بدون مدل، در ۷ دسته. زیر نام هر فرمول، بعد از یک خط، یک جملهٔ کوتاه می‌گوید به چه کاری می‌آید. جست‌وجو (کلید `/`)، فیلتر دسته، و پیوند «پر کردن با مثال». ارقام فارسی (۸٫۴۰) پذیرفته می‌شوند؛ فهرست‌ها را با کاما جدا کنید |
| داده‌های کلان | ۱۱ سری FRED و BIS، مستقیم از منبع. اگر منبع در دسترس نباشد، عددی جایگزین نمی‌شود |
| معاملهٔ کاغذی | پیش‌نمایش ← بررسی ۱۷گانهٔ ریسک ← تایپ `CONFIRM` ← ثبت. لغو، تطبیق، کلید توقف اضطراری |
| گزارش ممیزی | رکوردهای پرسش و معامله، با بررسی سالم بودن زنجیرهٔ هش |
| نگهداری | گزارش فاز ۱۰ (همان `tools/maintain.py`) |
| ارائه‌دهنده‌ها | انتخاب موتور پیش‌فرض، افزودن ارائه‌دهندهٔ شخصی، تغییر آدرس پایه و مدل، آزمون اتصال. خود کلیدها هرگز نمایش یا ذخیره نمی‌شوند (بخش «ارائه‌دهنده‌ها» در پایین) |
| فاز ۱۱ (معلق) | به درخواست شما معلق است، چون فعلاً کارگزاری در کار نیست. پیش‌نیازها و تمرین کلید توقف فقط نمایش داده می‌شوند. هیچ دکمه‌ای برای فعال کردن ندارد |

## منابع داده در صفحهٔ «بازارها»

| منبع | چه چیزی | به‌روزرسانی |
|---|---|---|
| بانک مرکزی اروپا (ECB) | نرخ مرجع ۲۹ ارز | روزانه، حدود ۱۴:۱۵ به وقت اروپای مرکزی |
| BIS | نرخ بهرهٔ سیاستی ۴۹ بانک مرکزی | روزانه؛ سری‌های متوقف‌شده (بیش از ۴۰۰ روز) علامت می‌خورند |
| FRED | بازده اوراق ۲، ۱۰ و ۳۰ سالهٔ آمریکا، نفت WTI و برنت، گاز، شاخص دلار | روزانه |
| بانک جهانی | تورم، رشد، بیکاری، بدهی، تجارت و ... | سالانه |
| Alpha Vantage | قیمت پایانی روز سهام، جست‌وجوی نماد، ۹ جفت‌ارز فارکس | روزانه، با کلید شخصی |
| CoinGecko | بازار رمزارزها (Powered by CoinGecko) | هنگام باز کردن زبانه دریافت و ۱۰ دقیقه در حافظه نگه داشته می‌شود؛ بدون کلید یا با کلید Demo |
| SEC EDGAR | صورت‌های مالی سالانه از گزارش 10-K (درآمد، سود خالص، EPS، دارایی‌ها و ...) | پس از هر گزارش سالانه؛ با ایمیل تماس |

کنار گذاشته شده‌اند: Kraken (شرایطش ساکنان ایران را مستثنا می‌کند) و Binance (صفحهٔ شرایطش قابل بررسی نبود).

- هیچ‌کدام قیمت لحظه‌ای یا قابل معامله نیست.
- نرخ متقاطع (مثلاً ین به دلار) فقط از نرخ‌های **همان روز** محاسبه می‌شود؛ اگر تاریخ دو ارز فرق کند، تبدیل انجام نمی‌شود.
- داده‌ها ۱۰ دقیقه در حافظه نگه داشته می‌شوند و روی دیسک ذخیره نمی‌شوند. اگر منبعی در دسترس نباشد، پیام خطا نمایش داده می‌شود، نه عدد جایگزین.

## ارائه‌دهنده‌ها: آنلاین یا آفلاین

- **پیش‌فرض آفلاین است** (مدل محلی؛ هیچ داده‌ای از رایانه خارج نمی‌شود). در حالت آنلاین، سؤال و داده‌های بازیابی‌شده به ارائه‌دهندهٔ انتخابی فرستاده می‌شود.
- تنظیمات در `%USERPROFILE%\.marfin\providers.json` ذخیره می‌شود، بیرون از پوشهٔ پروژه. **کلید API در این فایل نوشته نمی‌شود**؛ هر مقداری که شبیه کلید باشد رد می‌شود. کلید را فقط در متغیر محیطی بگذارید، مثلاً `$env:GROQ_API_KEY="..."`.
- **افزودن ارائه‌دهندهٔ شخصی:** نام کوتاه، گویش API (سازگار با OpenAI، Anthropic یا Google Gemini)، آدرس پایه و نام متغیر محیطی کلید (مثلاً `MYLAB_API_KEY`). نام تکراری یعنی ویرایش. آدرس باید `https` باشد، یا `http://localhost:PORT/v1` برای سرور روی همین رایانه.
- **تغییر آدرس پایه یا مدل** هر ارائه‌دهندهٔ داخلی، و «بازگشت به پیش‌فرض».
- **آزمون اتصال** فقط فهرست مدل‌ها را می‌گیرد و توکنی مصرف نمی‌کند. ریدایرکت دنبال نمی‌شود تا کلید به میزبان دیگری فرستاده نشود.
- ارائه‌دهندهٔ پولی یا با هزینهٔ نامعلوم فقط با تیک «اجازهٔ ارائه‌دهندهٔ پولی یا نامعلوم» اجرا می‌شود.
- اگر فایل تنظیمات خراب باشد، برنامه به آن دست نمی‌زند، خطا را نشان می‌دهد و با موتور آفلاین ادامه می‌دهد.

## ظاهر و موبایل

- دکمهٔ تغییر تم (روشن/تیره) بالای صفحه است و انتخاب شما در همین مرورگر به خاطر سپرده می‌شود.
- در صفحه‌های باریک (موبایل و تبلت)، منوی کناری به یک منوی کشویی بالای صفحه تبدیل می‌شود.
- در صفحهٔ «پرسش»، `Ctrl+Enter` فرم را ارسال می‌کند و دکمه‌های نمونه، سؤال را پر می‌کنند.

## معاملهٔ کاغذی

- برای **ثبت** سفارش (نه پیش‌نمایش)، این دو خط را در `%USERPROFILE%\.marfin\execution.conf` بنویسید:
  ```
  mode = PAPER_TRADING
  i_have_enabled_paper_trading = yes
  ```
  رابط کاربری خودش این فایل را نمی‌نویسد. فعال کردن یک حالت باید کار انسان باشد.
- قیمت bid/ask/last را **خودتان** وارد کنید. برنامه دادهٔ لحظه‌ای مجاز ندارد، و قیمت با برچسب
  `USER_SUPPLIED` ثبت می‌شود. قیمتی که بیش از ۵ ثانیه از ورودش گذشته باشد رد می‌شود.
- سقف‌ها از `configs/risk-policy.json` خوانده می‌شوند (که تأییدش کرده‌اید).

## امنیت

- سرور فقط روی `127.0.0.1` گوش می‌دهد و از شبکه و اینترنت در دسترس نیست. `ui.py --host` با هر نشانی دیگری رد می‌شود.
- هر فرم یک توکن تصادفی دارد. سایت دیگری نمی‌تواند از طریق مرورگر شما سفارش ثبت کند.
- هر متنی که از مدل یا منابع می‌آید escape می‌شود. اگر پاسخ مدل حاوی کد باشد، به‌صورت متن نمایش داده می‌شود.
- سیاست امنیت محتوا (CSP) سخت‌گیرانه است: هیچ اسکریپت یا استایل درون‌خطی مجاز نیست، و فقط دو فایل ثابت `app.css` و `app.js` از خود برنامه بارگذاری می‌شوند. صفحه بدون JavaScript هم کامل کار می‌کند.
