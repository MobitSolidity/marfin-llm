## ۵) گرید کنید — سه نشست جدا

```powershell
python tools\grade_persian.py --input evidence\phase4_merged_2026-09-03.json --output evals\results\r10_grades_2026-09.json --arm rag
python tools\grade_persian.py --input evidence\phase4_merged_2026-09-03.json --output evals\results\r10_grades_2026-09.json --arm plain
python tools\grade_persian.py --input evidence\phase4_merged_2026-09-03.json --output evals\results\r10_grades_2026-09.json --arm tools
```

| بازو | موارد | تخمین |
|---|---|---|
| `rag` | ۱۰ | ~۸ دقیقه |
| `plain` | ۲۱ | ~۱۶ دقیقه |
| `tools` | ۲۱ | ~۱۶ دقیقه |

هر سه دستور **آزموده شده‌اند** و به‌ترتیب ۱۰ / ۲۱ / ۲۱ مورد می‌دهند.

**resumable است** و بعد از **هر** حکم ذخیره می‌کند. هر وقت خواستید `q` بزنید و
بعداً همان دستور را دوباره اجرا کنید.

### واژگان حکم

| کلید | حکم |
|---|---|
| `1` | GOOD — فارسی روان، طبق rubric، بدون ادعای بی‌پشتوانه |
| `2` | WEAK — قابل‌فهم ولی ناهموار |
| `3` | BAD — فارسی غیرقابل‌قبول، یا rubric نادیده گرفته شده |
| `4` | WRONG_LANGUAGE — زبان اشتباه |
| `5` | UNSUPPORTED — روان، ولی عددی را ادعا می‌کند که پشتوانه ندارد |

`s` رد کردن · `q` خروج (ذخیره‌شده)

## یک محدودیت که باید بدانید

این گرید **`persian_fluency_regression_pct_max` را سبز نمی‌کند.** آن یک متریکِ
**رگرسیون** است و خط پایه‌ای برای مقایسه ندارد. کاری که این گرید می‌کند ساختنِ
**خط پایهٔ اول** است — که مقایسهٔ آینده را ممکن می‌کند.

ارائهٔ اولین اندازه‌گیری به‌عنوان «عبور از آستانه» همان خطای
ESTIMATED-به‌جای-MEASURED است که این پروژه ممنوع کرده، پس آن را نخواهم کرد.

**پس چرا ارزش دارد؟** کیفیت فارسی مدل الآن **هیچ‌جا** ثبت نشده · حکم FAIL قبلی
روی اجرای **آلوده** بود · و اندازه‌گیری D-0081 نشان داد مجموعهٔ ادعاهای مشکوکِ
ماشین با مجموعهٔ انسان **هم‌پوشانی صفر** داشت — ماشین جای خوانندهٔ انسانی را
نمی‌گیرد.

**ایمنی:** فایل ورودی **فقط‌خواندنی** باز می‌شود. گریدها به فایل جداگانه
می‌روند. این ابزار **هرگز** `phase_4/measurements_recorded` را نمی‌نویسد.
